# 荣景音乐｜RONGJING MUSIC

荣景音乐是荣景文川的音乐曲库与播放空间。它负责**收录、整理、收藏和播放作品**；AI 音乐生成、分轨、翻唱与音频处理能力由独立的 Sonviaf 项目承担。

> 让音乐，回到生活里。

## V1 功能

- 浏览公开曲库，搜索歌曲、艺术家和专辑。
- 播放 / 暂停、上一首、下一首、进度拖动、音量控制。
- 播放队列、随机播放、列表循环和单曲循环。
- 收藏歌曲、最近播放记录。
- 导入本地音频文件；文件保存在当前浏览器的 IndexedDB 中，不会上传到服务器。
- 响应式界面，支持桌面浏览器和移动浏览器。
- 不依赖前端框架或第三方 JavaScript 播放库，可作为静态网站部署。

## 公开曲库

公开曲目由 data/catalog.json 驱动。添加或修改曲目时，维护曲目 ID、标题、艺术家、专辑、时长、音源地址和封面主题色即可，不需要修改播放器逻辑。

音源地址目前沿用旧 Moodify Web Player 曲目表中的 play.rongjingmusic.com/audio/... 路径。**该地址及每首音频的可访问性尚未在本次代码提交中验证**；部署前由 Codex 检查网络、跨域策略、HTTP Range 支持与真实播放结果。若音源地址变化，只修改 data/catalog.json。

曲目清单的来源参考：[Moodify 旧 Web Player 页面](https://github.com/huliye24/moodify-ai/blob/e24b29f57276999b378f46a478c1914f6198e685/apps/web/app/page.tsx)。新播放器采用独立的 HTML / CSS / JavaScript 实现，不依赖旧播放器的 Next.js 页面或 API 客户端。

## 本地曲库与隐私

- 使用“导入音乐”选择本地音频文件。
- 音频二进制文件保存在浏览器 IndexedDB；收藏、最近播放、音量和播放偏好保存在浏览器本地。
- 本地文件不会上传到荣景音乐服务器。
- 清除网站数据或更换浏览器 / 设备可能会清除本地曲库；重要原文件仍应保存在自己的设备或备份中。
- 浏览器实际支持的音频格式因浏览器和操作系统而异。文件选择器接受常见音频格式，但接受文件不代表浏览器一定能够解码。

## 静态运行方式

需要通过 HTTP 服务打开项目，避免 file:// 环境对 fetch() 与资源加载的限制。例如：

    python -m http.server 8000

随后访问 http://localhost:8000。此命令仅用于本地开发说明；本次提交未运行项目或测试。

## 产品边界

当前 V1 是**静态前端播放器 + 浏览器本地曲库**：

- 尚无用户账户、跨设备同步、云端上传、后台曲目管理或服务端数据库。
- 公开音源必须由可访问的媒体 URL 提供；本仓库不包含音频二进制文件。
- 不在播放器中实现 Sonviaf 的生成、分轨、翻唱或音频处理逻辑。
- 未来如需公开发布新作品，可先继续使用 catalog.json；曲目规模和运营需求增长后，再设计管理端与曲库 API。
